# 🌷 Среќен 8-ми март, мамо

Лична еднострана веб-страница направена како подарок за 8-ми март, Меѓународниот ден на жената. Топол и нежен мини-сајт со ракописно писмо, полароид галерија од семејни моменти и сертификат „за најдобрата мајка" подготвен за зачувување како PDF.

## ✨ Карактеристики

- 🌸 **Hero секција** со CSS анимација на падечки ливчиња (без JavaScript библиотеки)
- 💌 **Ракописно писмо** стилизирано како лист хартија, со топла лична порака
- 📷 **Полароид галерија** со 6 семејни фотографии и интерактивни hover ефекти
- 💖 **Картички со спомени** — „Твојата сила", „Твојата нежност", „Твоите гушки"
- 📜 **Сертификат за најдобрата мајка** на засебна страна, подготвен за зачувување како PDF
- 📱 **Целосно responsive** — еднакво убаво изгледа на мобилен, таблет и десктоп
- 🎨 **Деликатни микро-анимации** низ целата страна за течно искуство

## 🛠️ Технологии

- **HTML5** — семантичка структура
- **CSS3** — Grid, Flexbox, custom properties, keyframe анимации, scroll-driven animations
- **Google Fonts** — Playfair Display, Dancing Script, Poppins
- **Без JavaScript framework-ови** — чист и едноставен код

## 💡 Како да ја персонализираш за себе

| Што | Каде |
|-----|------|
| Фотографии | Замени ги `photo1.jpg` до `photo6.jpg` во `assets/images/` |
| Текст на писмото | `index.html` → `<section class="letter">` |
| Име на мама | `certificate.html` → означено со HTML коментар |
| Бои | `style.css` → `:root` CSS променливите |
| Поднаслови на фотографиите | `index.html` → `<figcaption>` елементите |

## 📄 Зачувување на сертификатот како PDF

1. Отвори ја `certificate.html` во прелистувач
2. Притисни `Ctrl + P` (или `Cmd + P` на Mac)
3. Избери **„Save as PDF"** како дестинација
4. Готово ✨

## 🎯 Што научив од овој проект

- Работа со **CSS Grid** и **Flexbox** за комплексни responsive layout-и
- Креирање **keyframe анимации** без потпирање на библиотеки
- Имплементирање на **scroll-driven animations** со модерен CSS
- Користење на **CSS custom properties** за лесно одржлива палета на бои
- Print-specific styling преку `@media print`
- Семантички и пристапен HTML5
